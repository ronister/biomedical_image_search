# Biomedical Similar Image Search Using Multimodal Open-Source Models

## Project Overview
This project implements a similar image search system specifically designed for biomedical images using state-of-the-art multimodal open-source models. The system enables efficient retrieval of visually similar medical images from a database, which can be valuable for medical research, diagnosis support, and educational purposes.

## Author
**Roni Shternberg**

## Features
- Multimodal image similarity search
- Support for various biomedical image formats
- Efficient indexing and retrieval system
- User-friendly interface for image queries
- Scalable architecture for large image databases

## Technical Stack
- Python
- Deep Learning Framework (PyTorch)
- Open-source Multimodal Models
- Vector Database for similarity search: ChromaDB
